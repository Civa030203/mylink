# 마이링크 (MyLink) - 제품 요구사항 정의서 (PRD)

## 1. 프로젝트 개요

*   **프로젝트명**: 마이링크 (MyLink)
*   **목적**: 인스타그램, 틱톡 등 여러 개의 링크를 등록할 수 없는 플랫폼에서 단 하나의 링크(`mylink.com/@username`)를 통해 사용자의 모든 활동, 포트폴리오, 소셜 미디어 채널을 모아서 보여줄 수 있는 '통합 링크 프로필 서비스' 구축.
*   **대상 사용자**: 
    *   여러 SNS 채널을 운영하는 크리에이터 및 인플루언서
    *   자신의 작업물을 모아서 보여줘야 하는 프리랜서 및 취업 준비생 (포트폴리오 용도)
    *   여러 상품 페이지나 예약 링크를 제공해야 하는 소상공인

---

## 2. 핵심 기능 목록

기능은 초기 출시를 위한 **필수(Mandatory)** 기능과 향후 고도화 또는 차별화를 위한 **선택(Optional)** 기능으로 구분합니다.

### ⚾️ 필수 기능 (MVP - 초기 런칭 목표)
1.  **회원 인증 및 계정 관리**: 구글 소셜 로그인 전용 (Firebase Auth), 로그아웃, 회원탈퇴
2.  **프로필 관리**: 사용자 고유 ID(URL용), 프로필 이미지, 닉네임, 간단한 소개글(Bio) 편집
3.  **링크 관리 시스템**: 일반 링크(URL) 추가, 제목 설정, 수정, 삭제 및 노출 순서 변경
4.  **퍼블릭 프로필 뷰어**: 외부인이 접속했을 때 보여지는 사용자 고유의 퍼블릭 페이지 렌더링

### 🌟 선택 기능 및 개선 제안 (추가 도입 고려)
1.  **테마 및 시각적 커스터마이징**: 배경색, 버튼 스타일, 폰트 등 디자인 변경 기능
2.  **소셜 미디어 전용 아이콘 링크**: 일반 버튼 외에 화면 하단 등에 아이콘 형태로 배치되는 특수 링크
3.  **성과 분석 (Analytics)**: 프로필 총 방문자 수(조회수) 및 개별 링크 클릭 수 트래킹
4.  **오픈그래프(OpenGraph) 및 SEO 최적화**: 마이링크 URL을 카카오톡/문자 등으로 공유시 보여지는 썸네일과 설명글 렌더링
5.  **QR 코드 자동 생성**: 오프라인 명함이나 홍보물에 바로 사용할 수 있는 프로필 전용 QR코드 다운로드

## 3. 기능 상세 설명

### 3.1 필수 기능 상세

*   **회원 인증 및 계정 관리**
    *   Firebase Auth를 이용한 구글 소셜 로그인 전용 (이메일/비밀번호 등 복잡한 가입 절차 생략).
    *   로그아웃 및 서비스 탈퇴 기능 포함.
*   **프로필 관리**
    *   신규 가입 시 고유 주소로 사용되고 화면에 노출될 **DisplayName(활동명)과 실명(Real Name)**을 설정하는 필수 온보딩 제공.
    *   DisplayName은 접속 URL(`mylink.com/displayname`)로 사용되며, 프로필 화면에서 실명과 함께 노출됨.
    *   설정된 DisplayName과 실명은 추후 설정에서 언제든지 자유롭게 **변경 가능**함.
    *   프로필 사진 업로드 및 짧은 소개글(Bio) 작성.
*   **링크 관리 시스템**
    *   **링크 추가**: 새 버튼을 눌러 링크 제목(Title)과 목적지 URL 입력. (초기 MVP는 일반적인 URL 링크 버튼 구성에 집중)
    *   **토글 기능**: 링크를 삭제하지 않고 단순 숨김/노출 처리(On/Off 스위치).
    *   **순서 변경**: 마우스 드래그 앤 드롭을 이용한 직관적인 링크 버튼 순서 변경.
*   **퍼블릭 프로필 뷰어**
    *   모바일 환경에 최적화된 반응형 디자인 제공.
    *    관리자(본인)가 아닌 일반 방문자가 접속하면 읽기 전용으로 프로필과 버튼들만 노출됨.

### 3.2 선택 기능 상세 (제안)

*   **테마 시스템**
    *   사용자가 일일이 색상을 지정하지 않아도 바로 적용 가능한 여러 가지 프리셋 테마 제공 (이전 대화에서 언급된 'Neobrutalism' 스타일 등).
*   **성과 분석**
    *   대시보드 화면에서 기간별 방문자 수 추이, 각 링크가 클릭된 횟수를 시각적으로 제공하여 마케팅 자료로 활용 가능하게 함.
*   **오픈그래프 커스텀**
    *   사용자가 자신의 프로필 링크를 공유할 때 나타날 썸네일 이미지 및 미리보기 제목/설명을 직접 설정할 수 있도록 함.

## 4. 기술 스택 (Tech Stack)

*   **Frontend Framework**: Next.js
*   **Styling & UI**: Tailwind CSS, shadcn/ui (해당 컴포넌트 활용 후 점진적으로 자체 디자인 시스템 적용 예정)
*   **Backend & DB (BaaS)**: Firebase (Auth: 구글 로그인, Firestore: 사용자 및 링크 데이터, Storage: 프로필 이미지)
