# 마이링크 (MyLink) - 사용자 시나리오 (User Scenarios)

## 1. 신규 유저 온보딩 (Onboarding Flow)
**목적**: 서비스에 처음 가입한 유저가 자신만의 고유 주소를 만들고 서비스를 시작하기까지의 경험.

1. **서비스 접속**: 유저가 메인 랜딩 페이지(`mylink.com`)에 접속하여 서비스 소개를 확인하고 `[Google로 시작하기]` 버튼을 클릭한다.
2. **소셜 로그인 인증**: 구글 로그인 팝업이 뜨고 계정 인증을 완료한다.
3. **신규 유저 판별**: 시스템은 해당 구글 계정이 처음 로그인한 신규 유저임을 판별하고, 즉시 온보딩 화면(`/onboarding`)으로 리다이렉트 시킨다.
4. **DisplayName 및 실명 설정**: 
   - 화면에 "당신을 나타낼 프로필 정보를 설정해주세요"라는 문구와 인풋 창이 보인다.
   - 첫 번째 인풋에 고유 URL로 쓰일 'DisplayName'을 입력하고, 두 번째 인풋에 '사용자 실명'을 입력한다.
   - 실시간으로 중복 여부를 체크하며, 유효한 경우 `[생성하기]` 버튼이 활성화된다.
5. **완료 및 정책 안내**: "입력하신 이름들은 가입 후 자유롭게 변경 가능합니다."라는 안내를 확인 후 버튼을 누른다. 성공적으로 아이디가 등록되며 대시보드 화면(`/admin`)으로 자동 이동된다.

## 2. 링크 추가 및 관리 (Link Management)
**목적**: 유저가 프로필 페이지에 노출될 새로운 링크를 쉽게 추가하고 순서를 바꾸는 경험.

1. **대시보드 진입**: 대시보드 메인 화면 좌측에 관리 패널, 우측에 스마트폰 모양의 실시간 미리보기(Preview) 뷰어가 나타난다.
2. **링크 블록 생성**: `[+ 새 링크 추가]` 버튼을 누르면 새로운 빈 링크 카드(블록)가 상단에 추가된다.
3. **정보 입력**: 유저가 해당 카드 내에 '제목(Title)'과 'URL 주소'를 입력한다.
4. **노출 활성화**: 입력을 완료하고 카드 우측의 토글(Switch)을 On 상태로 변경하면, 우측의 실시간 미리보기 화면에 입력한 버튼이 짠 하고 즉시 나타난다.
5. **순서 변경**: 여러 개의 링크가 있을 때, 특정 링크 카드 좌측의 핸들(≡) 영역을 마우스로 잡고 위아래로 끌어서 놓으면(Drag and Drop) 순서가 즉각 변경되며 우측 뷰어에도 순서가 스와핑되어 표시된다.

## 3. 프로필 정보 수정 (Profile Editing)
**목적**: 방문자에게 보여질 프로필 사진과 소개글을 설정하는 경험.

1. **탭 이동**: 대시보드의 '프로필' 탭으로 이동한다.
2. **이미지 업로드**: 비어있는(기본 아바타) 프로필 이미지 영역을 클릭하여 본인의 사진 파일을 선택, 업로드한다. 사진이 자동으로 원형으로 크롭되어 표시된다.
3. **텍스트 작성 및 변경**: 'DisplayName'과 '사용자 실명(Real Name)'을 자유롭게 수정하고, 100자 정도의 짧은 '소개글(Bio)'을 작성한다.
4. **저장 및 확인**: `[저장하기]` 버튼을 누르면 "프로필이 업데이트되었습니다"라는 알럿(Toast)창이 뜨며, 우측 라이브 미리보기 화면에 즉시 본인의 모습(DisplayName 및 실명 동시 표시)이 반영된 것을 확인한다.

## 4. 퍼블릭 프로필 열람 (Public View)
**목적**: 관리자가 아닌 일반 방문자가 홍보된 유저의 프로필을 열람하는 경험.

1. **외부 유입**: 누군가 크리에이터의 인스타그램 프로필 등에서 `mylink.com/displayname` 링크를 클릭한다.
2. **화면 렌더링 (모바일 최적화)**: 모바일 디바이스에 꽉 차는 깔끔한 프로필 페이지가 로드된다. 상단에는 원형 프로필 이미지와 'DisplayName' 그리고 '사용자 실명'이 함께 노출되며 소개글이 이어진다. 하단에는 관리자가 활성화(On) 해둔 링크 버튼들이 일정한 간격(shadcn/ui 기반 디자인)으로 나열되어 있다.
3. **외부 이동**: 방문자가 관심 있는 버튼 하나를 탭(Tap)하면 즉시 해당 유튜버의 콘텐츠나 예약 페이지, 혹은 포트폴리오 사이트가 새 탭으로 열린다.
