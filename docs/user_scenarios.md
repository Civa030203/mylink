# 마이링크 (MyLink) - 전체 사용자 시나리오

본 문서는 서비스에서 발생할 수 있는 모든 유스케이스(Use Case)를 '사용자는 __하기 위해 __한다'의 지정된 형식으로 작성한 완전한 시나리오 문서입니다.

---

## 1. 방문자 (Visitor)
### 프로필 열람 및 상호작용
- 사용자는 **크리에이터(소유자)의 통합 프로필 및 여러 링크를 한눈에 확인하기 위해** 인스타그램 등 외부 플랫폼에 등록된 `mylink.com/displayname` 링크를 **클릭(또는 탭)한다.**
- 사용자는 **해당 크리에이터의 기본 정보를 파악하기 위해** 상단에 렌더링된 프로필 사진, DisplayName, 사용자 실명 및 소개글을 **읽어본다.**
- 사용자는 **본인이 원하는 영상, 쇼핑몰, 예약 사이트 등의 목적지로 이동하기 위해** 관심 있는 내용이 적힌 링크 버튼을 **클릭한다.**
- 사용자는 **해당 서비스에 매력을 느껴 자신만의 통합 링크 페이지를 만들기 위해** 페이지 최하단에 위치한 'Powered by MyLink' 로고 배너를 **클릭한다.**

### 예외 및 오류 대응
- 사용자는 **존재하지 않거나 변경된 잘못된 주소로 접속했을 때 올바른 경로를 안내받기 위해** 나타나는 404 Not Found 화면에서 '메인 홈으로 가기' 버튼을 **클릭한다.**

---

## 2. 소유자 (Owner)
### 회원가입 및 온보딩 (초기 진입)
- 사용자는 **서비스에 가입하여 내 페이지를 셋업하기 위해** 랜딩 페이지에서 `[Google로 시작하기]` 버튼을 **클릭하여 계정을 인증한다.**
- 사용자는 **나만의 고유한 접속 URL을 생성하기 위해** 최초 로그인 시 나타나는 온보딩 화면에서 영문/숫자로 된 DisplayName을 **입력한다.**
- 사용자는 **방문자들에게 신뢰감을 주고 활동명과 실명을 함께 노출하기 위해** 두 번째 입력 폼에 자신의 실명(Real Name)을 **입력한다.**
- 사용자는 **입력한 아이디(DisplayName)가 사용 가능한지 빠르게 확인하기 위해** 시스템이 제공하는 실시간 중복 확인 피드백 텍스트(성공/에러 메시지)를 **확인한다.**
- 사용자는 **입력한 프로필 정보로 온보딩 절차를 마무리하기 위해** 활성화된 `[생성하기]` 버튼을 **클릭한다.**

### 로그인 및 계정 (보안) 관리
- 사용자는 **기존에 생성해 둔 프로필과 링크 데이터에 접근하기 위해** 메인 화면에서 `[Google 로그인]`을 눌러 **로그인한다.**
- 사용자는 **더 이상 공용 기기에서 내 계정에 접근할 수 없도록 상태를 해제하기 위해** 대시보드 환경설정 혹은 하단 메뉴의 '로그아웃' 버튼을 **클릭한다.**
- 사용자는 **마이링크 서비스 이용을 완전히 중단하고 개인정보 파일과 DB 데이터를 파기하기 위해** 설정 화면에서 '회원 탈퇴' 버튼을 **클릭한다.**

### 프로필 페이지 설정 (프로필 탭)
- 사용자는 **방문자에게 시각적인 정체성과 얼굴을 보여주기 위해** 비어있는(기본) 아바타 영역을 클릭하여 본인의 이미지 파일을 선택 및 **업로드한다.**
- 사용자는 **크리에이터명(활동명)이나 개명 등으로 이름이 바뀌었을 때 이를 최신화하기 위해** DisplayName 필드와 실명 필드의 텍스트를 기호에 맞게 자유롭게 **수정한다.**
- 사용자는 **방문자에게 자신이 운영하는 채널이나 본인을 간략히 소개하기 위해** 자기 소개(Bio) 텍스트에어리어에 영역에 100자 이내의 소개글을 **작성한다.**
- 사용자는 **입력 및 변경한 모든 프로필 정보를 서버에 안전하게 반영하기 위해** 폼 하단의 `[저장하기]` 버튼을 **클릭한다.**

### 링크 등록 및 관리 (링크 탭)
- 사용자는 **새로운 홍보 목적지(블로그, 굿즈 샵 등)를 프로필에 등록하기 위해** 대시보드의 `[+ 새 링크 추가]` 버튼을 **클릭한다.**
- 사용자는 **방문자가 해당 버튼이 어떤 링크로 연결되는지 명확히 인지할 수 있도록** 생성된 링크 카드에 '구독하기', '내 포트폴리오' 등의 '제목(Title)'을 **입력한다.**
- 사용자는 **버튼 클릭 시 방문자가 실제 랜딩 랜딩될 도착 지점을 지정하기 위해** 'URL' 입력란에 올바른 웹 주소 형식(https://...)을 **입력한다.**
- 사용자는 **추가한 링크를 실제 퍼블릭 프로필 화면에 노출시키기 위해** 해당 카드의 우측 상단에 위치한 활성화 스위치(Toggle)를 On 상태로 **변경한다.**
- 사용자는 **특정 행사 기간이 끝나는 등 임시로 링크를 감추고 싶을 때 삭제하지 않기 위해** 해당 카드의 활성화 스위치를 Off 상태로 **변경한다.**
- 사용자는 **현재 집중적으로 홍보해야 할 더 중요한 링크를 상위에 노출시키기 위해** 링크 카드 좌측의 드래그 핸들(≡) 영역을 마우스로 잡아 위아래로 **드래그 앤 드롭한다.**
- 사용자는 **더 이상 유효하지 않은 과거의 링크를 목록에서 영구적으로 지우기 위해** 해당 링크 카드의 '휴지통(삭제)' 아이콘을 **클릭한다.**
- 사용자는 **실수로 중요한 링크를 완전히 삭제하는 사고를 방지하기 위해** 삭제 확인 경고 팝업창에서 '최종 삭제 확인'을 **클릭한다.**

### 프리뷰 및 홍보 공유
- 사용자는 **내가 현재 편집/저장한 정보들이 스마트폰 화면 환경에서 방문자에게 어떻게 노출되는지 실시간으로 점검하기 위해** 대시보드 우측의 실시간 뷰어를 번갈아가며 **확인한다.**
- 사용자는 **내 완성된 마이링크 프로필을 여러 SNS 채널 프로필에 복사해 홍보하기 위해** 대시보드 상단(또는 화면 헤더)에 제공되는 `내 링크 복사하기(Share)` 버튼을 **클릭한다.**
